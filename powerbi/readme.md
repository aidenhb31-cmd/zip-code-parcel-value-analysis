# Overview

The dataset was analyzed and filtered to show ZIP codes in the Cary/Raleigh area have been visualized in Power BI to view areas with high concentrations of parcels worth more than $1 million dollars and their respective median parcel values. Median parcel value differentials could be used to identify outliers, as well as determine the statistical significance of the median parcel data for that zip code. 

# Potential Applications

This data could potentially be applied in the context of investor research, market research, and geographic comparison.
